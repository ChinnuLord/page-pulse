# Page Pulse

## Overview
Page Pulse is a full-stack web application that analyzes websites for SEO, accessibility, and performance metrics.

## Features

- Website SEO Audit
- Accessibility Analysis
- Metadata Extraction
- Audit History
- REST API
- Responsive UI

## Tech Stack

Frontend
- React
- Vite
- Material UI

Backend
- Node.js
- Express

Database
- MongoDB Atlas

Testing
- Jest
- Supertest

Deployment
- Render
- Vercel

## Installation

git clone ...

cd server
npm install

cd ../client
npm install

MONGO_URI=

Server

npm start

Client
